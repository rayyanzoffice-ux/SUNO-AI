# 3-Day Hackathon Plan

## Day 1 - Build Mock Prototype

| Time | Frontend | Backend / Logic |
|---|---|---|
| First | App structure | Models |
| Second | Main screens | RiskEngine |
| Third | Mock navigation flow | Mock DetectionResult |
| Fourth | Push frontend branch | Push backend branch |

## Day 1 Target

The app must run with mock data.

Flow:

Home → Monitoring → Simulate Detection → Safety Check → Emergency Alert → Trusted Contact View → History

## Day 2 - Integration

| Time | Frontend | Backend / Logic |
|---|---|---|
| First | Pull backend data | Expose DetectionResult |
| Second | Connect UI states | Connect risk logic |
| Third | Connect actions | Connect incident statuses |
| Fourth | Push integration | Push integration |

## Day 2 Target

Frontend should no longer depend only on hardcoded screen data.

## Day 3 - Demo Polish

| Time | Frontend | Backend / Logic |
|---|---|---|
| First | Fix UI bugs | Fix flow bugs |
| Second | Polish screens | Test risk cases |
| Third | Build APK | Prepare fallback mock mode |
| Fourth | Practice demo | Practice demo |

## Final Demo Order

1. Open SUNO
2. Start monitoring
3. Show monitoring active
4. Trigger detection
5. Show Safety Check
6. Let countdown expire or press Can't Respond
7. Show Emergency Alert
8. Show Trusted Contact View
9. Press I Am Checking
10. Show History
